# Phishing Awareness Lab

Plataforma educacional local para conscientização sobre phishing.

## Tecnologias
- Python
- Flask
- SQLite
- HTML, CSS e JavaScript

## Instalação

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Acesse http://127.0.0.1:5000

## Funcionalidades
- Dashboard
- Desafios educativos
- Simulador de mensagens fictícias
- Analisador básico de texto
- Relatórios e pontuação

Somente para treinamento e conscientização em ambiente local.
