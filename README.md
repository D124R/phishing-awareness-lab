\# 🛡️ Phishing Awareness Lab



A Python-based educational laboratory designed to demonstrate phishing awareness concepts and help users understand how to identify suspicious messages and improve cybersecurity awareness.



\## 📌 About



The \*\*Phishing Awareness Lab\*\* is an educational project focused on cybersecurity awareness, threat analysis, and learning about phishing techniques from a defensive perspective.



\## ✨ Features



\- Phishing awareness demonstrations

\- Campaign analysis module

\- Educational dashboard

\- Web interface

\- Data management using SQLite



\## 🛠️ Technologies



\- Python

\- Flask

\- SQLite

\- HTML5

\- CSS3

\- JavaScript

\## ⚙️ Installation



Clone the repository:



```bash

git clone https://github.com/D124R/phishing-awareness-lab.git

```



Enter the project directory:



```bash

cd phishing-awareness-lab

```



Create a virtual environment:



```bash

python -m venv venv

```



Activate it on Windows:



```bash

venv\\Scripts\\activate

```



Install dependencies:



```bash

pip install -r requirements.txt

```



\## ▶️ Running the Project



```bash

python app.py

```



Open the local address displayed by the application in your browser.
